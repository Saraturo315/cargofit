# Container Fit Calculator

A single-page tool that estimates how many units of a cargo fit into each standard shipping container (20' GP, 40' GP, 40' HC, 45' HC, 20' Reefer, 40' Reefer HC), limited by volume and by payload weight, with a rotatable 3D load view.

Open `index.html` in a browser, or visit the GitHub Pages link for this repository.

Container inside sizes and payloads are typical ISO values. Confirm with your carrier before booking.
